implementation claims use the source-of-truth hierarchy from the Phase 1 brief;
legacy OKF and bootstrap files are evidence of what was documented, not
authoritative implementation evidence.

The ledger is intentionally separate from the document disposition matrix:
one legacy document can contain claims with different statuses.
